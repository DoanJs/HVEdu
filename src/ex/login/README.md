# AnKhangLoginPage

## Cách dùng

Copy thư mục `AnKhangLoginPage` vào project React, ví dụ:

```txt
src/pages/AnKhangLoginPage/
  index.js
  LoginPage.jsx
  LoginPage.css
```

Import:

```jsx
import LoginPage from './pages/AnKhangLoginPage';
```

Trang có sẵn responsive desktop/mobile và overlay loading khi bấm đăng nhập.
